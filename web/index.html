📖 Cách sử dụng

  1. Lần đầu: chạy python web/server.py rồi mở http://127.0.0.1:5050.
  2. Phân tích mới: menu «Phân tích mới» → chọn video → «Bắt đầu phân tích».
  3. Xem lại: menu «Kết quả đã lưu» → bấm «Xem» (không cần chạy lại AI).
  4. Chi tiết: thống kê + video output ở menu «Xem chi tiết».

⚙️ Pipeline

YOLOv8m → Skeleton (MediaPipe) → ST-GCN — preset chính xác, giống step3_classroom_demo.py.
